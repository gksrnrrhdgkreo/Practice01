# 🫧 버블파이터 웹 (Bubble Fighter Web)

> **순수 HTML5, CSS3, Vanilla JavaScript**로 구현한 3인칭 슈터(TPS) 캐주얼 웹게임입니다.  
> 외부 라이브러리, 빌드 도구, 외부 이미지 에셋 없이 HTML Canvas 절차적 그래픽과 Web Audio API 합성 사운드만으로 구동됩니다.

---

## 🎮 게임 특징
- **3인칭 슈터(TPS) 시점**: 3D 투시 원근 투영(Perspective Projection) 및 오버숄더 카메라
- **2 vs 2 팀전 대전**: 블루팀(플레이어 + AI 다오) vs 레드팀(AI 디지니 + AI 모스)
- **무기 시스템**: 
  - `1번` 샷건 (근접 고위력 산탄)
  - `2번` 물총 (연사 및 중거리 견제)
  - `3번` 망치 (근접 타격 및 확정 팡)
- **버블파이터 핵심 룰**:
  - **버블 (Bubble)**: 체력이 0이 되면 사망하지 않고 무지개빛 물방울에 갇힘
  - **팡 (PANG!)**: 버블에 갇힌 적에게 근접하여 좌클릭하면 완전 처치 (팀 점수 +1)
  - **헬프 (HELP!)**: 버블에 갇힌 아군에게 몸을 부딪히면 구출 및 체력 회복
  - **5초 무적**: 리스폰 시 5초간 황금빛 네온 쉴드 돔과 함께 무적 적용

## 🕹️ 조작법
| 키 | 기능 |
| :--- | :--- |
| **W, A, S, D** | 전진 / 좌 / 후진 / 우 이동 |
| **마우스 이동** | 360도 3인칭 시점 회전 및 조준 (포인터 락) |
| **마우스 좌클릭** | 무기 발사 / 버블 근접 팡 |
| **1, 2, 3** | 무기 교체 (1:샷건, 2:물총, 3:망치) |
| **R** | 재장전 |
